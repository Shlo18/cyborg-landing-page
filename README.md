# 🤖 CYBORG — Futuristic Landing Page

A responsive, sci-fi themed landing page built with modern **HTML5**, **CSS3**, and **JavaScript**, showcasing AI integration, cybernetics, and human enhancement technologies.

---

## 🌟 Key Features

* **🎨 Cyberpunk Aesthetic:** Dark mode color scheme with neon accents, custom glowing buttons, and glassmorphic card elements.
* **📱 Fully Responsive:** Clean layout across mobile, tablet, and desktop devices.
* **⚡ Interactive UI:** Smooth scrolling navigation links, hover transitions, and interactive image gallery.
* **🚀 Lightweight & Zero Dependency:** Pure vanilla HTML, CSS, and JS with zero bloated libraries.

---

## 🛠️ Tech Stack

* **HTML5:** Semantic document structuring
* **CSS3:** Flexbox, Grid, CSS variables, and keyframe animations
* **JavaScript:** DOM manipulation and event handlers

---

## 🚀 Quick Start

To preview this project locally:

```bash
# Clone the repository
git clone https://github.com/Shlo18/cyborg-landing-page.git

# Open the project directory
cd cyborg-landing-page

# Launch index.html in your default browser (or use Live Server)
start index.html
```
